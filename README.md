# Olist-Brazilian-E-Commerce
Proyek analisis data E-Commerce Public Dataset (Olist Brazilian E-Commerce). Berisi notebook analisis data end-to-end (Data Wrangling → EDA → Visualisasi → RFM &amp; Geospatial Analysis → Conclusion &amp; Recommendation) serta dashboard interaktif menggunakan Streamlit.

# Setup Environment - Shell/Terminal
```
pipenv install
pipenv shell
pip install -r requirements.txt
pip install streamlit pandas matplotlib seaborn folium geopandas streamlit-folium
```

# Run steamlit app
```
cd dashboard
streamlit run dashboard.py
```
